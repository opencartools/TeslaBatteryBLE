# CI overview

Moved out of `AGENTS.md`; the workflows in `.github/workflows/` are the source of truth.

- CI (`.github/workflows/android.yml`): core tests, debug build, release smoke test (`assembleSmoke -PdemoCar=true`: the minified release build plus the simulated car, driven on an emulator by `.github/scripts/smoke-test.sh`: install, pair, wake, wait for the charge line, no crash in logcat), Go fixture diff, rolling preview release (tag releases take their screenshots from the Paparazzi full-screen snapshots and require a green smoke test for the tagged commit). `pr-paparazzi.yml` (UI PRs) renders the card snapshots (light + dark) and diffs them against the PR's merge base with main without secrets; `pr-paparazzi-comment.yml` posts the diffs as PR comments from the default branch. `website-preview.yml` (`website/**` PRs) captures without secrets; `website-preview-comment.yml` posts the results as PR comments from the default branch.
- `PR builds` release: every same-repo PR push publishes its debug APK (`TeslaBatteryBLE-pr<N>-<sha7>.apk`) to one rolling prerelease titled **PR builds**, replacing that PR's previous APK. `pr-builds-cleanup.yml` deletes it when the PR closes, and every publish also prunes the assets of PRs that are no longer open. The assets are plain download links, so a PR can be installed from a phone without a GitHub login and without unzipping an Actions artifact; they are not app releases and are not meant for Obtainium.
- `actionlint.yml` (Workflow lint): actionlint, with shellcheck on `run:` steps, plus shellcheck on `.github/scripts/*.sh`, whenever `.github/workflows/**` or `.github/scripts/**` changes. It never builds the app.
- The smoke job and `exploratory.yml` boot the emulator through one composite action, `.github/actions/emulator`, so the API level and boot options are set in one place. The screenshot walk (`capture-screenshots.sh`) is no longer part of the smoke job; the exploratory job and `tools/demo-emulator.sh` use it.
- `notification-screenshot.yml` (manual dispatch with a branch or tag and an API level, 36 by default): builds the smoke APK of that ref, runs `capture-screenshots.sh` on an emulator and uploads the walk, including the tracking notification in the shade (`06-notification.png`), as the `notification-screenshots` artifact. For looking at the Android 16 progress-style notification of a PR before merging.
- `exploratory.yml` (daily 03:41 UTC, and manual dispatch with a monkey seed): builds the smoke APK, runs `.github/scripts/explore.sh` on the emulator (scripted walk, font scale, rotation, process death, seeded monkey run) and files one deduplicated `exploratory-finding` issue per crash, ANR or unformatted value. It skips days when nothing outside the docs, website, fastlane and screenshot-workflow paths changed since the last successful run. Judged from the UI tree and logcat only.
